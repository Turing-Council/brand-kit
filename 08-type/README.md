# Typography

| Role | Font | Weight | Size / line height | Tracking |
|---|---|---|---|---|
| Display | Poppins | Bold | 64 / 64 | −3% |
| Headline 1 | Poppins | Bold | 40 / 44 | −2% |
| Headline 2 | Poppins | SemiBold | 28 / 34 | −1% |
| Body | Poppins | Regular | 16 / 26 | 0 |
| Caption | Poppins | Medium | 13 / 18 | 0 |
| Label | JetBrains Mono | Medium | 12 / 16, uppercase | +10% |

Both fonts are free (SIL Open Font License):

- Poppins: https://fonts.google.com/specimen/Poppins
- JetBrains Mono: https://fonts.google.com/specimen/JetBrains+Mono

Fallback when Poppins isn't available: Arial.

The name in every logo file is already converted to outlines, so the logo files don't need the fonts installed.
