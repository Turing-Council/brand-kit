# Turing Council brand kit

Version 1.0 · November 2026 · Marketing and Communications

Start with `brand-book/tc-brand-book.pdf`. It explains when to use each file.

| Folder | What's inside |
|---|---|
| `01-logo/` | The cube on its own. `svg/` masters and `png/` at 512, 1024 and 2048 px, transparent or on navy. Colour, mono white, mono black, mono navy. |
| `02-lockup/` | Cube with the name, with or without "The voice of DTU Compute". Horizontal and stacked, in dark, light, mono white and mono black. PNG at 1200 and 2400 px wide. `-bg` files include their background. |
| `03-app-icon/` | Navy app icon, square and rounded, 1024 and 512 px. |
| `04-web/` | `favicon.ico`, `favicon.svg`, PNG favicons, `apple-touch-icon.png`, `icon-192/512.png`, `site.webmanifest`, email signature logo. |
| `05-social/` | Profile pictures, banners and covers, and post, story and slide backgrounds at each platform's size. |
| `06-pattern/` | The bit grid pattern: four study-line bands, mixed, one per study line, and with TURING hidden in it. |
| `07-colour/` | `tc-colours.ase` (import into Affinity, Adobe or Figma), `tc-colours.css`, `tc-colours.json` and a swatch sheet. |
| `08-type/` | Font links and the type scale. |
| `09-motion/` | Comeback animation (13 s, 60 fps, silent): Instagram post 1080×1350, story/reel 1080×1920, horizontal 1920×1080, square 1080×1080, plus an end frame of each. |
| `brand-book/` | The brand book as PDF. |

## Naming

`tc-[what]-[variant]-[background]-[size].png`

- `tc-logo-color-transparent-1024.png`: colour cube, transparent, 1024 × 1024
- `tc-lockup-horizontal-tagline-dark-2400w.png`: horizontal lockup with tagline, white text, 2400 px wide
- `tc-banner-linkedin-company-1128x191.png`: exact upload size

`dark` means made for dark backgrounds (white text). `light` means made for light backgrounds (navy text, cube in its navy tile).

## Colours

DTU Navy blue, White and the four study-line colours are DTU's official colours: https://designguide.dtu.dk/colours (CMYK and Pantone values for print are listed there). The assignment of colours to study lines is the council's own.


| Name | Hex | Use |
|---|---|---|
| DTU Navy blue | `#030F4F` | Main background |
| White | `#FFFFFF` | Text, cube letters |
| Lilac | `#C3C6EC` | Secondary text on navy (our addition, not a DTU colour) |
| DTU Orange | `#FC7634` | Human-Centered AI |
| DTU Purple | `#79238E` | Mathematical Modelling and Computation |
| DTU Bright green | `#1FD082` | Autonomous Systems |
| DTU Blue | `#2F3EEA` | Computer Science and Engineering |

## Rebuilding

Everything except the brand book is generated by `../tools/build_final.py` (SVG masters) and `../tools/render_png.mjs` (PNG). Change a value there and run both again, rather than editing files by hand.
